# StableSMPSpawn

StableSMPSpawn is a Minecraft Paper plugin designed to enhance the spawn experience on your server. It includes features like teleportation to spawn, spawn protection, bedless death handling, and more. The plugin is compatible with Paper 1.21.4 and requires Java 21.

## Install

1. Download the StableSMPSpawn.jar file from the provided link.
2. Place the JAR file in the `plugins` folder of your Paper server.
3. Restart or reload your server to load the plugin.

## Use

1. **Teleport to Spawn**: Use the `/spawn` command to teleport to the server spawn.
2. **Set Spawn**: Use the `/stablesmp setspawn` command to set the spawn location (requires OP permission).
3. **Reload Configuration**: Use the `/stablesmp reload` command to reload the plugin configuration (requires OP permission).
4. **Spawn Protection**: The plugin protects the spawn area from block breaking and placing, and disables PvP within a 45-block radius.
5. **Bedless Death Handling**: Players without a bed or respawn anchor will be teleported to spawn upon death.
